# T02-cad195 — Horn pilot recess radial fit (Ø19.2 horn in the printed recess)

Variant of `T02`: CAD 19.50 + 0.3x45 mouth chamfer (prints about Ø19.35 ±0.10)

- Requirement: Recess slides onto the horn by hand (clearance >= 0.02) and float stays small enough to centre the gripper (<= 0.30).
- Spec: LSL 0.020, USL 0.300 mm diametral clearance
- Acceptance: MC (Cpk ≥ 1.33, percentile method)
- Model: linear; source file `T02_pilot_recess_fit.yaml`; seed 20260922

Base = the stock Ø20.0 recess: 20.0 - 19.2 = 0.8 diametral (0.4 radial), not the 0.4 so101.md row 12 states. The recess is only 1.0 mm (5 layers) deep, so first-layer squish affects all of it when the mount face prints on the bed; a 0.3x45 mouth chamfer removes that term. Under the assumed scatter no CAD size reaches Cpk 1.33 (see results/sweep_T02_recess_d_cad.md); the coupon (section 8) must shrink the scatter first.
